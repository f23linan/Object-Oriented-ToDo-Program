# Java ToDo List

## Description
A ToDo List application developed in Java using the Swing library for its graphical user interface (GUI). The application allows users to create, edit, remove and organise different types of tasks.

## Features
- **Task Types:** Create Home, Study and Selfcare tasks.
- **Task Management:** Add, edit and remove tasks.
- **Completion Tracking:** Mark tasks as completed or uncompleted.
- **Sorting:** Sort tasks alphabetically, by task type or by completion status.
- **Status Bar:** Displays the number of tasks and their completion status.
- **Graphical Interface:** Interactive desktop application built using Java Swing.

## Technologies
- Java
- Java Swing
- Object-Oriented Programming
- Event Handling
- Java Modules

## Dependencies
This project uses the `it401g.todo` module provided as part of a university assignment.

The module includes task interfaces and predefined task types used by the application.
